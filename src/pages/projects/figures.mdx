# what I did

I always wondered how Skate Canada made these, so I thought it would be fun to make my own web app for drawing skating steps.

I used React/TypeScript/Tailwind CSS and the [tldraw](https://tldraw.dev/) library, which provides a lot of the existing drawing framework. My main work was extending this to figure skating-specific steps (an example is in the [README](https://github.com/angelayzheng/figures) or on the [homepage](https://figures.angelazheng.ca/)).

Currently, my implementation is using a mix of Bézier curves and elliptical arcs to draw four skating turns: **3 turn**, **bracket**, **rocker**, and **counter**. Since they're currently children of the `Shape` class, they can be resized, rotated, and colour changed, but the individual control points of the component curves aren't movable. I'm planning to have them extend a different class and implement it that way. They also come with a default text label that can be edited.

Exporting drawings into SVG and PNG formats is easy, so this would genuinely be very useful to me as a coach, and for fun when I want to write down cool turn clusters! :D

# future plans

- Introduce dropdowns to select the actual foot/direction/edge and display the corresponding turn.
- Currently, turns can be put together consecutively and connected manually, but it's not the same as automatically doing a cluster of turns (which is a sequence of turns done on one foot -- equivalently, without lifting the pen from the page). Implementing this will be a lot of work in making the curves and control points interact properly.
- Add more turns and skating steps (normal edges, forward/backward stroking, twizzles, C-steps and S-steps, loops, etc.).
